A simple Python-based web application that performs fingerprinting using HTTP headers and SSL certificate analysis.

Built using:
- Python
- Streamlit

---

## Features

- Detects server information from HTTP/HTTPS headers  
- Checks SSL certificate details  
- Supports multiple websites at once  
- Fast scanning using multithreading  
- Clean UI using Streamlit  

---

## Output Example

For each website, the tool shows:
- HTTP Server Info
- HTTPS Server Info
- SSL Certificate Issuer
